# QMG Code

A fast, lightweight coding agent for your terminal. It reads your repo, edits
files, runs commands and tests — powered by [Qumge](https://qumge.com) models
and capabilities, with one account and one balance.

> **Status: early development.** Nothing is installable yet. Watch this repo.

## What it is

- **One key, many models.** Start with the models Qumge serves directly, switch
  to a premium model when a task needs it, and see what each one costs.
- **Pay as you go.** No seat licence. Pick a model per task instead of paying
  for a plan you don't use.
- **Your capabilities, monetised.** Publish a capability to the Qumge
  marketplace, earn from it, and spend the earnings on models at cost.

## Install

Not yet. Releases will be announced at [qumge.com](https://qumge.com).
